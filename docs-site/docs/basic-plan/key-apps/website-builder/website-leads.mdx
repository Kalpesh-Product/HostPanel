# Website Leads

**Website Leads** contains enquiries submitted through forms on the published business website.
Open **Key Apps > Website Builder > Website Leads**.

This page is for website-originated enquiries only. The separate [All Leads](/docs/basic-plan/key-apps/all-leads)
module combines website and Nomad enquiries.

## Page summary

The top cards show:

- **Total Website Leads** — for all website enquiries;
- **Pending** — for leads still requiring follow-up;
- **Closed** — for completed or closed enquiries.

![Website Leads page with counts, filters, search and empty state](/img/basic-plan/website-leads.gif)

Below the cards, use **All**, **Pending**, and **Closed** to filter the list. The search field
helps you locate a lead using the fields supported by the page.

## Receive a website lead

A lead is created when a visitor submits an enquiry or contact form on the live website.
Service-specific enquiry actions can include the relevant service or offering in the submitted
information. The website must be published and its form flow must be working before this page can
receive real leads.

When testing a newly published website:

1. Open the public website URL.
2. Submit a clearly labelled test enquiry using a website form.
3. Return to **Website Leads** and confirm that **Total** and **Pending** increase.
4. Open the new lead and compare its contact and enquiry details with the submitted form.
5. Confirm that the lead is scoped to the correct company and workspace.

## Search, filter, and status

Use the status buttons to focus on pending follow-up or closed work. Use search when the list
contains multiple enquiries. Clear the search and return to **All** before deciding that a lead is
missing.

:::note
When a list is filtered or a search returns nothing, the page shows **No matching website leads
found**. The same wording can represent either an empty account or a genuine filtered no-match
state.
:::

## Follow up and close

Open a lead to review the available visitor details and enquiry context. Complete the required
follow-up, then use the page's status action to mark the lead **Closed** when no further action is
required. Re-check the **Closed** filter to confirm the record moved correctly and remains
searchable.

## Recommended operating practice

- Check **Pending** leads regularly.
- Confirm contact information before responding.
- Use the enquiry context to understand which service interested the visitor.
- Avoid closing a lead until the required follow-up is complete.
- Use [All Leads](/docs/basic-plan/key-apps/all-leads) when website and Nomad enquiries need to be reviewed together.
