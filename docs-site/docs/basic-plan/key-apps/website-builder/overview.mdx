# Website Builder Overview

**Website Builder** is the entry page for creating and managing a business website in the Basic
Host Panel. Open **Key Apps > Website Builder**.

The page does not contain the full website editor itself — it routes you to four separate
functional pages:

- **Create or Edit Website** — build and publish your site.
- **Website Leads** — enquiries submitted through the published site.
- **Website Review** — visitor-submitted reviews.
- **Careers** — job openings and applications.

Each of these has its own documentation.

![Website Builder hub with Edit Website, Website Leads, Website Review and Careers](/img/basic-plan/website-builder-hub.png)

## Page layout

The page heading is **Website Builder**, followed by a short description explaining that you can
create, edit, and publish a company website and manage its leads and reviews. A **Guide** starts
a walkthrough of the page and its four cards.

## Create or Edit Website card

For a new business, the first card is **Create Website**. It opens the business-service and
template selection flow before entering the editor. When a matching website record already
exists for the active company or workspace, the card changes to **Edit Website** and opens the
saved website.

Website ownership is checked against the active company or workspace, so a website belonging to
another saved company context cannot be opened for the current host. Draft and published website
states are also considered when deciding which card to show.

→ See [Create and Edit Website](/docs/basic-plan/key-apps/website-builder/create-and-edit-website).

## Website Leads card

**Website Leads** opens enquiries submitted through forms on the published website. You can
review contact details and organise enquiries as **Pending** or **Closed**. This page is specific
to the website source; the separate [All Leads](/docs/basic-plan/key-apps/all-leads) module combines
website and Nomad enquiries.

→ See [Website Leads](/docs/basic-plan/key-apps/website-builder/website-leads).

## Website Review card

**Website Review** opens visitor-submitted website reviews. You can search and filter reviews,
read the full feedback, and moderate it as **Pending**, **Approved**, or **Rejected**. Approved
feedback may be enabled for public display according to the available review controls.

→ See [Website Review](/docs/basic-plan/key-apps/website-builder/website-review).

## Careers card

**Careers** manages public job openings and applications received from the website. The card is
locked until a website has been created. If selected too early, the page displays
**Please create your website first**. After unlocking, you can configure vacancies and manage
incoming applications.

→ See [Website Careers](/docs/basic-plan/key-apps/website-builder/website-careers).

## Recommended first action

For a new workspace, start with **Create Website**. Website Leads, Website Review, and Careers
become useful once the website is configured and visitors begin interacting with it. Return to
this hub whenever you need to edit the website or manage one of its connected pages.
