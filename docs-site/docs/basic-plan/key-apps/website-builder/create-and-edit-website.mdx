# Create and Edit Website

The **Create or Edit Website** page is used to choose a website design, add business content,
preview the result, and publish or update the hosted website. Open **Key Apps > Website
Builder**, then select **Create Website** for a new site or **Edit Website** when a website
already exists.

## Choose the business services

Select **Create Website** to open **Choose a Template**. First choose the main business type.
Current choices include **Co-Working**, **Meeting Rooms**, **Cafe**, **Hostels**, **Co-Living**,
and **Workations**. The main choice determines which template is recommended and which service
leads the website.

Next, select any additional services. Each selected service receives its own service page. The
additional choices are optional and can be expanded later from the editor.

## Choose and preview a template

The template registry includes **Classic**, **Fresh Studio**, **Savor**, **Wayfarer**, **Haven**,
**Commons**, **Huddle**, **Warm Organic**, and **Emerald Studio**. Central availability settings
may hide or disable individual designs, so the visible list can vary.

Each template card includes a description and a **Preview** with sample content. Recommended
templates are placed first for the selected business type, but any enabled design may be chosen.
Select a card, then choose **Get started with [template name]**.

![Website Template with sample content preview](/img/basic-plan/template-preview.png)

:::note
The selection dialog states that the template cannot be changed after getting started. The editor
later offers a template-change request, which requires approval and can be limited by plan.
:::

## Understand the editor

The editor header identifies **Create Website** or **Edit Website**, the business type, the
active template, and the draft status. Draft autosave begins as you work. The status can show
**saving**, **saved** with a time, **restored from a previous session**, or **save failed**. If
saving fails, changes remain in the current form until another successful save or the session
ends.

![Website editor with page tabs, template badge and editable sections](/img/basic-plan/editor.gif)

If the website is empty, **Fill with sample content** can add placeholder text, photos, services,
reviews, and team information. Replace or remove every placeholder before publishing.

## Website pages

The page navigation covers **Home**, **About Us**, **Services**, **Gallery**, **Partner**,
**Careers**, and **Contact Us**. Page labels can be adjusted, and optional pages can be enabled or
disabled. The exact fields adapt to the selected service types and template.

**Home page** — can include the company name and logo, hero content and images, an introduction,
services, inclusions or amenities, frequently asked questions, gallery images, testimonials,
partner logos, contact information, social links, and footer content. Most optional sections
include an enable/disable control. Use real business information, optimised images, concise
headings, and contact details checked before publication.

**About Us page** — add the company introduction, story, mission, vision, values, founders, and
team members. Enable the page only after its content is complete, and remove sample people,
images, and descriptions.

**Services pages** — each selected service receives a dedicated page. Add the service heading,
description, images, offerings, prices, inclusions, and enquiry behaviour. Depending on the
service, the editor can represent rooms, desks, stays, menus, packages, and other offerings.
Website visitors use the enquiry controls to submit leads connected to that service.

**Gallery, Partner, Careers, and Contact pages** — use **Gallery** for business images,
**Partner** for partnership content and enquiries, **Careers** for job content and applications,
and **Contact Us** for the address, map, opening hours, phone, email, social links, and enquiry
form. Optional pages may remain disabled until ready.

## Preview the website

Choose **Preview** to open the current draft in a separate preview page. Your browser must allow
the popup. Before publishing, review:

- desktop and mobile readability;
- page navigation and enabled pages;
- company name, logo, text, and images;
- service descriptions, prices, and enquiry actions;
- address, map, contact details, and business hours;
- removal of sample or placeholder content.

![Preview of a generated company website](/img/basic-plan/website-preview.png)

## Website credits and publishing

Publishing uses website credits. The editor displays total credits, credits used, credits
remaining, and the reset date. If no credits remain, publishing is blocked until the displayed
reset date or the applicable allocation changes.

For a new website, select **Publish**, review the confirmation, and choose **Confirm and Publish**.
For an existing site, the action is shown as **Submit** and uses an update confirmation. Disabled
pages may trigger a warning, so you can continue with hidden pages, enable them, or return to
editing.

![Website credits controls and published URL](/img/basic-plan/credits-published-url.png)

After successful publication, the editor displays a **Published URL**. Open it to confirm the
public result, then share it with customers.

## Edit the website later

Return to **Key Apps > Website Builder** and select **Edit Website**. The editor restores the
saved or published site for the active business. Update content, preview it, and submit the
website update.

:::note
If another person is already editing the same website, an editing lock prevents simultaneous
changes from overwriting each other and identifies the active editor. Wait until the other editor
disconnects and the lock clears.
:::

A template change is not immediate. Use the editor's request control, review any plan quota, and
submit the request for approval. Continue using the current template until the request is
completed.

## Recommended workflow

1. Choose the main business and any additional services.
2. Preview the available templates and select one.
3. Add or replace all website content.
4. Enable only complete pages and sections.
5. Preview the full website and correct any issue.
6. Confirm that a website credit is available.
7. Publish and open the generated URL.
8. Return to **Edit Website** whenever content changes.
