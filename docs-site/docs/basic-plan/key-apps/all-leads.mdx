# All Leads

**All Leads** combines enquiries received from the published business website and WONO Nomad
listings. Open **Key Apps > All Leads**. Use this page when both sources need to be reviewed
together; [Website Leads](/docs/basic-plan/key-apps/website-builder/website-leads) and
[Nomad Leads](/docs/basic-plan/key-apps/nomad-listings/leads) remain available in their source modules.

![All Leads page with combined lead overview](/img/basic-plan/all-leads.gif)

## Summary cards

The top cards show:

- **Total All Leads** — website and Nomad enquiries combined;
- **Pending** — enquiries that still require attention;
- **Closed** — enquiries whose follow-up is complete.

Counts update when leads are received or their Host Panel status changes.

![All Leads summary cards](/img/basic-plan/all-leads-summary.gif)

## Filters and search

Use **All**, **Pending**, and **Closed** to narrow the list. Use search to locate a lead by the
values supported by the page. Clear search and filters before deciding that a lead is missing.

![All Leads status filters, search and empty result](/img/basic-plan/all-leads-filters.gif)

## Lead table and details

When records exist, the table shows lead name, contact information, source, product, status,
received date, and a details action. **Source** identifies whether the enquiry came from the
website or a Nomad listing. Open details to review the available contact and enquiry information
before following up.

## Manage lead status

Keep new or active enquiries **Pending** until the required response is complete. Change the Host
Panel status to **Closed** when no further action is required. Re-check the **Closed** filter to
confirm the change and ensure the record remains available for reference.

:::note
Basic does not show the report-export function — export is controlled by a higher-plan access
rule.
:::

## Recommended workflow

1. Open **Pending** leads.
2. Review the lead source and enquiry context.
3. Confirm contact information before responding.
4. Complete the required follow-up.
5. Mark the lead **Closed** only when finished.
6. Use the source-specific page when deeper Website or Nomad context is required.
