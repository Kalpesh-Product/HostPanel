# Visitor History

**Visitor History** contains past visitor records. Open **Key Apps > Visitor Management**, then
select **Visitor History**. Use it to review completed, cancelled, or rejected visits for a
selected month and year.

## Summary and period selection

The cards show a **Records — &lt;month&gt; &lt;year&gt;** count for the selected period, plus
**Checked Out**, **Cancelled**, and **Rejected**. Select the
month and year before reviewing counts or records. Search can locate a visitor within the loaded
period.

![Visitor History page with period filters, cards and records table](/img/basic-plan/visitor-history.png)

## Review a record

Use the row details action to inspect the visitor, badge, type, host or destination, visit
purpose, check-in time, check-out time, and final status where available. Confirm the selected
period if an expected visit is not shown.

## Export

An **Export** control is visible on Visitor History. Confirm the current plan entitlement and
verify that the exported rows follow the selected month, year, search, and status context.

:::note
Export is controlled by plan access — confirm your entitlement before relying on it for reporting.
:::

## Recommended workflow

1. Select the required month and year.
2. Review the summary counts.
3. Search for the visitor or inspect the table.
4. Open the record details.
5. Export only when the plan permits it and the selected rows have been verified.
