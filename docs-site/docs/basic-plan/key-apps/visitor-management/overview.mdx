# Visitor Management Overview

**Visitor Management** is the Basic-plan entry page for recording standard front-desk visitors and
reviewing visitor activity. Open **Key Apps > Visitor Management**.

The main page contains **Daily Visitors**, **Visitor History**, **Bookings**, and **Clients**
tabs, plus **New Frontdesk Action**.

![Visitor Management page with tabs, summary and New Frontdesk Action](/img/basic-plan/visitor-management.gif)

## Daily Visitors

**Daily Visitors** is the operational page for today's visitors. It provides live status counts,
search, status filters, row details, badge printing, and check-out actions.

→ See [Daily Visitors](/docs/basic-plan/key-apps/visitor-management/daily-visitors).

## Visitor History

**Visitor History** provides period-based past records using month and year filters. It includes
search, record summaries, details, and an export control.

→ See [Visitor History](/docs/basic-plan/key-apps/visitor-management/visitor-history).

## Locked Basic plan pages

**Bookings** and **Clients** are visible but disabled when the required feature grants are not
available. On Basic, do not expect **Walk-in Booking**, **Unit Tour**, **Verify Booking**, payment
proof, invoice handoff, external-client tracking, **Department Visitor**, or
**Tenant Company Visitor** unless those features are explicitly granted through another plan or
configuration.

## New Frontdesk Action

Select **New Frontdesk Action** to open the front-desk page. Under Basic, use **Standard
Visitor**.

→ See [Standard Visitor](/docs/basic-plan/key-apps/visitor-management/standard-visitor).
