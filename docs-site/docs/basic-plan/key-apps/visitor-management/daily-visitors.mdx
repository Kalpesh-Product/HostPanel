# Daily Visitors

**Daily Visitors** is the operational view for current-day visitor activity. Open
**Key Apps > Visitor Management**, then select **Daily Visitors**.

## Summary cards

The page shows **Checked-In Now**, **Pending Approval**, **Approved or Upcoming**, and
**Checked Out Today**. These counts summarize the visitor records available to the current
workspace and selected day context.

![Daily Visitors summary, filters, search and table](/img/basic-plan/daily-visitors.png)

## Filters, search, and table

Use **All**, **Pending**, **Approved**, **Checked In**, **Checked Out**, and **Rejected** to
filter records. Search helps you locate a visitor.

The table shows badge ID, visitor information, date, visitor type, host or destination, check-in
and check-out values, status, and actions.

![Visitor card badge](/img/basic-plan/visitor-badge.png)

## Manage a checked-in visitor

After a successful Standard Visitor check-in, the visitor appears here. Row actions can open
details, print the visitor badge, and check the visitor out when the visit ends.

![Checked in visitor row and actions](/img/basic-plan/checked-in-row.png)

## Check out

Select the check-out action only when the visitor has left. Review the confirmation, then choose
**Confirm Check-Out**. The system records the check-out time, marks the visit complete, and
changes the status to **Checked Out**.

![Visitor check-out confirmation](/img/basic-plan/check-out-confirmation.png)

## Recommended front desk practice

- Confirm the visitor identity and destination before check-in.
- Print a badge when required by the location policy.
- Keep Pending and Approved records under review.
- Check visitors out promptly when they leave.
- Open [Visitor History](/docs/basic-plan/key-apps/visitor-management/visitor-history) for completed past records.
