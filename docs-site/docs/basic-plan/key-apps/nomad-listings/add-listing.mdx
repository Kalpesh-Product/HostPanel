# Add Nomad Listing

The **Add Listing** page creates a new business-space listing for WONO Nomads. Open
**Key Apps > Nomad Listings > Listings**, then select **Add Listing**. Basic capacity must be
available before a new listing can be submitted.

## Before starting

Check **Listings Left** and **Product Types Used** on the Listings page. Basic supports four
non-deleted listings and two different product types. Reusing an existing type does not introduce
a third type, but adding a new type after the limit is reached is blocked.

## Business details

Enter the company title, optional website URL, and company type. Current types include
**Coworking**, **Meeting Room**, **Cafe**, **Workation**, **Coliving**, and **Hostel**. Select the
company type before choosing inclusions, because the inclusion list depends on that type.

Add the address, business description, country, state, city, Google Maps URL, latitude, and
longitude. Confirm that the map information points to the same physical location as the written
address.

![Add Nomad Listing form](/img/basic-plan/add-nomad-listing.gif)

## Images, logo, and review information

The form supports up to **ten** product images and **one** company logo. Use clear, current images
that belong to the business, and avoid uploading sensitive documents. Rating and total-review
fields should reflect an approved data source rather than an estimate. Any review information
added to the form should be accurate and suitable for public display.

## Submit and verify

Review required fields, spelling, location, inclusions, and images, then select **Submit**. After
submission:

1. Return to **Listings** and confirm that the new row belongs to the correct company.
2. Check its **Master Status** and **Visibility** separately.
3. Complete any required review or activation step.
4. Enable public visibility only when the listing is eligible.
5. Open the live listing and verify its public content.
