# Nomad Leads

**Nomad Leads** contains enquiries submitted from WONO Nomad listings. Open
**Key Apps > Nomad Listings > Leads**.

This page is source-specific. Use [All Leads](/docs/basic-plan/key-apps/all-leads) when website and Nomad
enquiries need to be reviewed together.

## Page summary

The summary cards show **Total Leads**, **Pending**, and **Closed**. Use **All**, **Pending**, and
**Closed** to filter the list. Search helps you locate a lead when the page contains multiple
enquiries.

![Nomad Leads page with counts, filters, search and empty state](/img/basic-plan/nomad-leads.gif)

## Receive and review a lead

A lead is created when a visitor submits an enquiry from a public Nomad listing. To verify a new
listing's enquiry flow, submit a clearly labelled test enquiry from the public listing, then
confirm that it appears here under the correct company, listing, product, and source.

Open the lead to review the visitor's available contact details and enquiry context. Complete the
required follow-up, then move the lead to **Closed** only when no further action is required.
