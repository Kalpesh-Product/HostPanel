# Nomad Listings — Listings

The **Listings** page shows all Nomad listings created or claimed for the active company. Open
**Key Apps > Nomad Listings > Listings**.

## Basic plan capacity

The summary cards show **Total Listings**, **Active**, **Inactive**,
**Product Types**, and **Listings Left**.

![Nomad Listings page with Basic capacity and empty table](/img/basic-plan/nomad-listings-list.gif)

:::note
Basic currently allows **four** non-deleted listings and up to **two** different product types.
Multiple listings may use the same type. The type limit applies when introducing a new type,
while publicly enabled listings are separately capped at four.
:::

## Search, filters, and table

Use **All**, **Active**, and **Inactive** to filter the list. Search can locate a listing by
supported values such as name, type, or city.

The table includes company, title, product type, location, Master Status, visibility, and
actions.

- **Master Status** indicates whether the listing is active in the management workflow.
- **Visibility** indicates whether an eligible listing is publicly shown.

:::note
Do not treat an **Active** management status as proof that the listing is already visible on
`wono.co`.
:::

## Add a listing

Select **Add Listing** to open the separate creation form. Before starting, confirm that
**Listings Left** is greater than zero and that adding the selected product type will not exceed
the two-type Basic limit.

→ See [Add Listing](/docs/basic-plan/key-apps/nomad-listings/add-listing).

## View, edit, and open publicly

Use the row actions to review a listing, edit its business and location information, or open the
live public listing when an active public URL is available. **View** mode is useful for checking
the complete record before changing it.

## Public visibility

The visibility action controls whether an eligible listing is shown on WONO Nomads. A listing
generally needs the required approval or active state before it can be public. Confirm the change
in the **Visibility** column and open the public link after enabling it.

![Listing visibility action and status](/img/basic-plan/listing-visibility.gif)

## Existing wono.co listing claim

**Verify Existing Listings on WONO.CO** opens a company search and claim flow. Select the matching
company and eligible listings, then send the request. An approved claim brings the existing
listings into the host account.

## Delete and recovery

**Delete** removes the listing from normal active use without necessarily erasing it permanently.
When recovery is available, select **Request Recovery**. The status changes to
**Recovery Requested** while the WONO team reviews it. Confirm any dependent state, including
visibility and capacity, before and after deletion.

![Deleted listing recovery request state](/img/basic-plan/recovery-request.gif)
