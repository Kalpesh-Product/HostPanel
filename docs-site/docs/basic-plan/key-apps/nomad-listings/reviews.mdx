# Nomad Reviews

**Nomad Reviews** manages visitor feedback submitted for WONO Nomad listings. Open
**Key Apps > Nomad Listings > Reviews**.

This page is separate from [Website Review](/docs/basic-plan/key-apps/website-builder/website-review),
which contains feedback submitted through the business website.

## Page summary

Summary cards show **Total Reviews**, **Pending**, **Approved**, and **Rejected**. Filters can
narrow reviews by status, rating, product type, and listing. Search can locate feedback using
reviewer, source, product, or description values.

![Nomad Reviews page with summary, filters and empty state](/img/basic-plan/nomad-reviews.gif)

## Review moderation

Open a row to read the full rating, description, listing, source, and current status. Approve
feedback that meets the agreed moderation policy. Reject spam, abusive, duplicate, irrelevant, or
otherwise disallowed content.

:::note
Critical feedback should be evaluated consistently rather than rejected only because it is
negative.
:::

For approved feedback, use the available public-display control to decide whether it appears on
the related Nomad listing. Verify important changes on the public listing.

## Recommended workflow

1. Open **Pending** reviews.
2. Read the complete review and confirm its listing.
3. Apply the approved moderation policy.
4. Approve or reject the review.
5. Confirm that the summary count and status filter update.
6. Verify public display when applicable.
