# Edit Nomad Listing

The **Edit Listing** page updates a Nomad listing already connected to the active company. Open
**Key Apps > Nomad Listings > Listings**, locate the correct row, and select its edit action. Use
the **View** action first when you only need to inspect the record.

## Review before editing

Confirm the company, title, product type, and location before making changes. The view page can
show business details, address, website, inclusions, images, reviews, and map information in
read-only form.

![Nomad listing read-only details](/img/basic-plan/nomad-listing-view.gif)

## Update the listing

Edit the title, website, type, inclusions, address, description, rating information, country,
state, city, map details, images, logo, or review information as required.

![Edit Nomad Listing form](/img/basic-plan/edit-nomad-listing.gif)

:::note
Changing the product type may be restricted if it introduces a third Basic-plan type. Review
type-specific inclusions after any type change.
:::

## Save and verify

Select **Submit** to save the updates. Return to **Listings** and confirm that the row shows the
expected title, type, location, and status. If the listing is public, open its live URL and verify
that the published content reflects the approved change. Some edits may require review before they
appear publicly.

## Safe editing practice

- Avoid replacing correct data when changing only one field.
- Keep a copy of important image or map information before removal.
- Re-check visibility after significant edits.
- Confirm that the listing remains associated with the correct company and workspace.
- Do not assume a saved edit is immediately live until the public page is checked.
