# Change Password

Open **Add Ons > Profile > Change Password**. This page lets the signed-in member replace the
account password after verifying the current password.

![Change Password page](/img/basic-plan/change-password.png)

## Verification step

Enter the current password and select **Verify**. The new-password fields remain disabled until
verification succeeds. The visibility icon beside each password field can show or hide the entered
value — use it only in a private environment.

If the current password is missing or incorrect, the page keeps the new-password fields unavailable
and displays an error. This protects the change flow from someone who gains temporary access to an
unlocked session.

## New password requirements

After verification, enter and confirm the new password. The page requires:

- at least **eight** characters;
- uppercase and lowercase letters;
- at least one number;
- at least one special character.

Both new-password values must match.

## Completing the change

Select **Submit** only after confirming the new password meets every requirement. A successful change
clears the form and returns the page to the unverified state.

:::note
Store the new password in an approved password manager and do not reuse it across accounts.
:::

## Recommended workflow

1. Work from a private device and network.
2. Enter the current password and select **Verify**.
3. Create a unique new password that meets all listed requirements.
4. Enter the same value in **Confirm Password**.
5. Select **Submit** and confirm the success message.
6. Sign in again if the application requests a new session.
