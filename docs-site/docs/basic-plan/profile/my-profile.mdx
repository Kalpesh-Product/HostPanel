# My Profile

Open **Profile > My Profile**. This page is your signed-in member record. It combines
identity, contact, employment, and organization information and lets you update permitted personal
details.

![My Profile page](/img/basic-plan/my-profile.png)

## Page layout

The profile header shows your photo, name, role, department scope, joining information, and
current status. The page then separates information into **Personal and Contact Details** and
**Work Details**. Depending on your access, it can also display company and department SOPs and
policies.

## Personal and contact details

The page can display full name, email, phone, gender, date of birth, current address, permanent
address, country, state, city, and emergency contact details. Missing values appear as a dash or
are omitted where the page intentionally hides unavailable optional fields.

![Edit profile data and detail](/img/basic-plan/edit-profile.png)

Select **Edit** to update the permitted fields. **Full name** and **email** are read only in this
form. Editable fields include:

- phone country code and number;
- gender and date of birth;
- country, state, and city;
- current and permanent addresses;
- emergency contact information.

Choosing **Same as current address** copies the current address into the permanent-address field.
State and city become available only after their parent location has been selected.

## Profile photo

The profile-photo control opens the current photo when one exists, or starts an upload when none
exists. After choosing a file, select **Save Photo** to apply it. Confirm the selected image is
appropriate before saving.

## Work details and documents

Work details can include employee ID, role, department, job title, job code, work location, work
mode, employment type, joining date, manager, notice period, shift, and probation. These values are
informational on this page and are not edited from the personal-details form.

Company and department document sections list available SOPs and policies. You may see all
departments or only the assigned department, depending on access. Empty sections clearly state that
no matching documents have been uploaded.

## Recommended workflow

1. Review the profile header and confirm the correct member is shown.
2. Check personal, contact, and work information.
3. Select **Edit** only when a permitted personal field needs correction.
4. Complete the dependent country, state, and city fields in order.
5. Select **Save Changes**, then confirm the updated values appear on the page.
