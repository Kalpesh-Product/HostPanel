# Plan and Billing

Open **Add Ons > Profile > Plan and Billing**. This page explains the workspace's current plan, the
modules available through that plan, and any recorded plan payments.

![Plan and Billing page](/img/basic-plan/plan-and-billing.png)

## Plan summary

The summary shows the plan name (**Basic Plan**), plan status, start date, and expiry date.

:::note
For a Basic workspace, start and expiry values can display as `--`, and the status may display as
`NONE`. These are system values rather than proof of an inactive account.
:::

## Included modules

The **Included Modules** tab lists enabled modules and groups them by product area. A typical Basic
account shows ten modules across **Common Modules**, **Key Apps**, **Core Modules**, and
**Tech Department**.

Use the list as the account-specific source of available modules. The module filter can show all
modules or plan modules, and search can locate an included module by name. A custom add-on filter
appears only when the selected plan supports it.

:::note
Do not assume that a module shown in another chart or marketing page is unlocked — check the
included-modules list for your own account.
:::

## Payment history

The **Payment History** tab lists plan-payment records when they exist, including plan, amount,
status, payment date, and invoice or payment-detail actions.

:::note
A Basic account with no rows displays **Basic plan has no payment history**. This is the expected
empty state for a free plan.
:::

## Upgrade and renewal actions

Basic workspaces can open the upgrade flow. Paid or trial plans can expose renewal messaging,
billing-cycle choices, and payment redirection.

## Recommended workflow

1. Confirm the displayed plan name.
2. Review the included-module count and grouped module list.
3. Use search or filters when checking a specific entitlement.
4. Open **Payment History** only when validating prior plan payments.
5. Start upgrade or renewal only after confirming plan scope, price, and billing cycle.
