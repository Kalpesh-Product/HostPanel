# Analytics

Open **Core Modules > Analytics**. The page reports performance across modules enabled for the
current unit and Basic plan. It has an updated timestamp and a **Refresh** control.

## Overview

The overview shows **Modules Tracked**, **Avg Activity Score** (out of 100), **Total Records**,
and **Open Items**. Two visualizations follow: a six-month platform activity trend and module
activity scores (top ten, out of 100). A **Module Wise Analytics** area groups tabs under Common
Modules, Key Apps, Core Modules, and Tech Department.

![Analytics overview](/img/basic-plan/analytics-overview.gif)

![Platform activity trend and module activity scores](/img/basic-plan/activity-scores.gif)

:::note
The chart labels can include modules beyond the visible Basic sidebar (for example, Attendance and
Meeting Room Booking with zero activity). Treat the graph as a comparison list, not evidence those
modules are unlocked.
:::

## Module-level examples

Each module card can show different details:

- **Customer Support** — total records, last-30-days records, open items, completion, and
  raised/resolved/pending counts, plus average resolution time, status breakdown, monthly trend, and
  peak days. An **Open Page** control links to the module.
- **Organization Management** — records, recent activity, activity score,
  member/department/pending-invite/access-change summary, membership breakdown, monthly trend, and
  peak days.
- **Access Grants** — records, activity score, roles/custom roles, members with extra access, access
  toggles, and a freshness breakdown.

![Customer Support status example in Analytics](/img/basic-plan/analytics-customer-support.gif)

:::note
Chart and module cards can count underlying records differently from the headline cards. Treat
screenshot values as example-account data, not plan limits.
:::
