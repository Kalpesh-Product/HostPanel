# Access Grants

Open **Core Modules > Access Grants**. The page manages user roles and module access for this unit.
It is distinct from the platform-user invitation flow in
[Organization Management](/docs/basic-plan/core-modules/organization-management).

## Page layout

Summary cards show **Total Members**, **Super Admin**, **Admin**, **Manager**, and **Employee**.
There are **All**, **Active**, and **Disabled** filters, a search field, and a role selector
containing Founder, Super-Admin, Admin, Manager, and Employee.

![Access Grants overview](/img/basic-plan/access-grants-overview.gif)

The table displays employee ID, platform user, email, access role, department, status, and actions.

![Access Grants member summary and filters](/img/basic-plan/access-grants-summary.gif)

:::note
The founder row shows **All Departments** access, and its sidebar-access and owner-role controls are
disabled and labelled **Self Protected**. Role changes are not made here.
:::

## Manage module access

For an eligible member, open **Sidebar Access** and enable only the modules required for that
person's responsibilities.

1. Open the member's **Sidebar Access**.
2. Enable only the modules the member needs. Access is grouped into areas such as Common Modules,
   Key Apps, and Core Modules.
3. Expand a module when page-level controls are available.
4. Select **Save Access**.

![Access Grants active member row](/img/basic-plan/access-grants-row.gif)

:::note
Changing module access does not change the member's role. Role promotion, demotion, and invitation
management belong in Organization Management. Verify effective permissions with the affected
member's account after saving.
:::

## Ownership transfer

Where available, **Transfer Ownership** is a separate Founder-only action. Review the proposed new
owner and every linked business unit before confirming, because ownership transfer changes who
controls the workspace.
