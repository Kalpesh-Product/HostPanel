# Add-ons Overview

**Add-ons** is a separate area of the Host Panel for optional and extended modules, shown
alongside **Common Modules**, **Key Apps**, **Core Modules**, and **Profile**.

:::note
Add-ons lists every optional module for your plan, grouped by area, with an enabled/locked count
per group. Which modules are enabled depends on your plan and the grants assigned to your account.
:::

## What to expect

- Add-ons is its own area, separate from **Profile**.
- Both enabled and locked modules are listed here; each group header shows an enabled/locked count.
- Some areas are visible but locked on the Basic plan until the required plan or grants are
  available.

## Module groups

Add-ons lists every module your workspace could have, grouped under up to five numbered headings:
**I. Common Modules**, **II. Extra Common Modules**, **III. Key Apps**, **IV. Core Modules**, and
**V. Department Accesses**. A group only appears if it has at least one module to show.

Within each group, modules are split into an **Enabled** row and, if any exist, a **Locked** row
below it. On Basic, **Workspace Settings** and **Workspace Management** (under Core Modules) are
always locked regardless of grants — they only unlock on a higher plan. **Department Accesses**
groups modules by department (HR, Administration, Sales, Finance, Maintenance, Tech, IT) and is
expandable per department; it typically has nothing to show on Basic, since Basic workspaces can't
create departments (see [Organization Management](/docs/basic-plan/core-modules/organization-management)).

Selecting an enabled module's card opens that module. Selecting a locked module's card opens the
**Upgrade Plan** window instead, if an upgrade path exists for it.

## Requesting an upgrade

The **Upgrade Plan** window offers **Professional** (with a monthly/annual toggle and, if a free
trial is available and not yet used, a **Start *N*-Day Free Trial** button) and **Custom**, which
opens a module picker so you choose exactly which add-ons to request. Selecting **Upgrade to
Professional** redirects to payment; selecting **Upgrade to Custom** sends a request to the WONO
team instead of unlocking anything immediately — the button then reads **Requested — Resend** if
you open the window again before it's actioned.

## Related areas

- [Profile](/docs/basic-plan/profile/my-profile) — personal, company, billing, and password settings.
- [Core Modules](/docs/basic-plan/core-modules/organization-management) — users, access grants, and analytics.
